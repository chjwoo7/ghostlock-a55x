# src/targets/

One directory per firmware, named `<codename>-<PDA>`:

```
src/targets/a55x-A556EXXU<PDA>/
├── target.h            # generated by tools/port_a55.py
└── p0_fingerprint.h    # generated by tools/port_a55.py
```

Rules:

- **one build, one directory.** Two PDAs never share a header, even on the same kernel version;
- `target.h` must carry `TARGET_PDA` matching the directory name and `TARGET_KERNEL_RELEASE` equal to the device's complete `uname -r`;
- nothing lands here without a hardware result. Unverified profiles belong in `docs/` and are labelled `experimental`;
- `port-report.md` from the derivation run belongs in the same directory so the unresolved list stays visible.

A PR adding a target must include the firmware identity, kernel `sha256`, both headers, the observed slide, and either a successful `id` from the root daemon or the exact crash trace.
